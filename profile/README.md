We make games that run in your terminal: drawn in its cells, played with its keys. Every one is free to play. The launcher, the site and the engine are open source; the games' code is not.

**The doors are not open yet.** The arcade is being built here, one part at a time.

Three games are moving in: `rustwake(6)`, `skyspear(6)` and `breakshot(6)`.

| Repository | What it holds |
|---|---|
| [usr.games](https://github.com/usrgames/usr.games) | The site: the front page, the devlog, the notices. |
| [tty1](https://github.com/usrgames/tty1) | The launcher: one command that installs the games, keeps them current, and starts them. |
| [rustwake.6](https://github.com/usrgames/rustwake.6) | rustwake's releases, signed, as tty1 installs them. |

Built on [glonk](https://glonk.dev).

We make games that run in your terminal: drawn in its cells, played with its keys. Every one is free, and all of the code is open.

**The doors are open at [usr.games](https://usr.games).** Play a game right in the page, or take the games home with one line:

```
curl -fsSL https://usr.games/install.sh | sh
```

| Repository | What it holds |
|---|---|
| [rustwake](https://github.com/usrgames/rustwake) | [`rustwake(6)`](https://usr.games/rustwake): clear the rogue machines out of a dark plant. |
| [skyspear](https://github.com/usrgames/skyspear) | [`skyspear(6)`](https://usr.games/skyspear): cave people, dinosaurs and falling stars. |
| [breakshot](https://github.com/usrgames/breakshot) | [`breakshot(6)`](https://usr.games/breakshot): eight-ball pool, alone or online. |
| [tty1](https://github.com/usrgames/tty1) | The launcher: one command that installs the games, keeps them current, and starts them. |
| [arcade](https://github.com/usrgames/arcade) | The relay two players meet through. |
| [usr.games](https://github.com/usrgames/usr.games) | The site: the front page, the devlog, the notices. |
| [glonk](https://github.com/usrgames/glonk) | The engine that draws the games, for anyone's terminal games. |
| [.github](https://github.com/usrgames/.github) | This page, and the release workflow every repository shares. |

# .github

What every usr.games repository shares.

| Path | What |
|---|---|
| `profile/README.md` | The page GitHub shows at the top of the organization. |

The picture at the top of that page is `site/card.png` of [usr.games](https://github.com/usrgames/usr.games), loaded from its `main` branch. A test draws it there, so it is not copied here.

When a repository joins the organization, or changes what it holds, its row on that page changes too.
